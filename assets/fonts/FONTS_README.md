# Arabic Fonts

Place the following font files in this directory before building the app:

## Required Fonts

### Amiri (body text — reader)
- `Amiri-Regular.ttf`
- `Amiri-Bold.ttf`
Download: https://github.com/aliftype/amiri/releases

### Reem Kufi (titles, headings)
- `ReemKufi-Regular.ttf`
- `ReemKufi-Bold.ttf`
Download: https://github.com/aliftype/reemkufi/releases

### Cairo (UI elements, labels)
- `Cairo-Regular.ttf`
- `Cairo-Bold.ttf`
Download: https://github.com/Gue3bara/Cairo/releases

## Alternative
You can also use `google_fonts` package to fetch them at runtime,
but for offline use, bundled fonts are required.

```bash
# Quick download example
wget -O Amiri-Regular.ttf "https://github.com/aliftype/amiri/raw/master/fonts/Amiri-Regular.ttf"
wget -O Amiri-Bold.ttf "https://github.com/aliftype/amiri/raw/master/fonts/Amiri-Bold.ttf"
wget -O ReemKufi-Regular.ttf "https://github.com/aliftype/reemkufi/raw/master/fonts/ReemKufi-Regular.ttf"
wget -O ReemKufi-Bold.ttf "https://github.com/aliftype/reemkufi/raw/master/fonts/ReemKufi-Bold.ttf"
wget -O Cairo-Regular.ttf "https://github.com/Gue3bara/Cairo/raw/master/fonts/Cairo-Regular.ttf"
wget -O Cairo-Bold.ttf "https://github.com/Gue3bara/Cairo/raw/master/fonts/Cairo-Bold.ttf"
```
